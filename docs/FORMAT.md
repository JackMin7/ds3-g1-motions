# 格式说明

[简体中文](FORMAT.md) | [English](FORMAT_EN.md)

每个片段仅有 `motion.bvh` 和 `motion.csv`。目录清单中的 `frames`、`fps`、`duration_seconds`、`files` 是播放及校验依据。

## BVH：人体骨架

人体骨架，根为 `Hips`。偏移和位置通道为厘米，Y 向上；欧拉旋转单位为度。当前导出使用 YXZ 旋转通道，但读取器仍应遵循文件内每个关节的 CHANNELS 顺序。帧率为 `1 / Frame Time`。

CSV 与 BVH 来自同一片段、帧数相同、帧时间一致；因为骨架及单位不同，空间值不应直接逐列比较。对比展示可将 BVH 的厘米转为米，Y-up 转为 Z-up：`(x, y, z) -> (x, -z, y) / 100`。这只是展示坐标换算，不是新的机器人重定向。

## CSV：G1 动作

无表头，N 行、36 列。世界 Z 向上。列 0–2 是根 XYZ（米），列 3–6 是根四元数 XYZW；列 7–35 是 29 个身体与手腕关节角（弧度），不含手指。

精确关节顺序为 `data/schema.json` 的 `csv.columns` 和 `csv.joint_order`，它是此 G1 模型的运动学顺序，不是通用执行器顺序。

## 时间

逐片段使用目录内真实 FPS，不固定假定 30 或 60。第 i 帧对应 i/fps 秒，首尾时间戳跨度为 `(N-1)/fps`，逐帧保持的播放周期为 `N/fps`。短片段和两帧片段未补帧或自动拼接。

清单还记录文件 SHA-256 与字节数。校验工具检查目录完整性、哈希、帧数、有限数值、四元数和帧率；这些检查不等于动力学认证。
